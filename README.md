# Love Cat's – Галерея и информационный портал

Многостраничный веб-сайт на чистом HTML, CSS и JavaScript с интерактивной галереей, слайд-шоу и интеграцией внешнего API.

## Основные возможности
- **Интерактивная галерея**: кастомный слайдер с модальным окном, возможностью множественного выбора фотографий и их пакетного скачивания.
- **Режим слайд-шоу**: с настройкой скорости воспроизведения и управлением с клавиатуры.
- **Интеграция с API**: получение и отображение актуальных курсов валют ЦБ РФ в реальном времени через Fetch API.
- **Адаптивная верстка**: корректное отображение на мобильных устройствах и десктопах.

## Стек технологий
- HTML5 (семантическая верстка)
- CSS3 (модульная структура, Flexbox)
- JavaScript (ES6+, работа с DOM, асинхронность)
- GitHub Pages (для деплоя)
